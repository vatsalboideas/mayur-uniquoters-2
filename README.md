# Mayur Uniquoters Limited (Next.js)

Next.js App Router rewrite of the original Vite + React SPA. Look, content, data, and behavior are preserved; navigation now uses real routes.

## Routes

| Path | Page |
|------|------|
| `/` | Home |
| `/market-segments` | Market segments index |
| `/market-segments/automotive` | Automotive |
| `/market-segments/furnishing` | Furnishing |
| `/market-segments/footwear` | Footwear |
| `/market-segments/leather-goods` | Leather goods |
| `/plants` | Plants |
| `/sustainability` | Sustainability |
| `/global-presence` | Global presence |
| `/news` | News |
| `/contact` | Contact |

## Scripts

```bash
npm install
npm run dev
npm run build
npm start
```

Dev server defaults to [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- Motion
- Lucide React
